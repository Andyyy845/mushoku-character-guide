# 角色圖片來源與授權紀錄

目前沒有收錄角色圖片，等待使用者提供具公開網站使用授權的素材。不得將尚未取得的圖片填入角色資料，也不得把搜尋結果視為授權。

## 存放方式

- 圖片：`characters/<id>.webp`，也接受 png、jpg、jpeg、avif。檔名只用小寫英數字與連字號。
- JSON：`"image": "./assets/characters/<id>.webp"`；未有素材就留空或省略。
- 保留作品比例，不拉伸；建議使用適合網頁的檔案大小。不要任意裁掉署名或權利標示。
- 每張圖必須先記錄下表，確認角色正確且授權涵蓋公開網站展示；完整私密授權文件不放進公開 Repository。
