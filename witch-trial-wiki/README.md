# 魔法少女的魔女審判｜無劇透角色百科

以官方公開設定製作的繁體中文非官方粉絲角色百科。提供 13 位角色的簡短介紹、囚人編號與已公開魔法；不整理案件答案或後期劇情。黑紫、暗紅與金色的哥德介面使用 CSS 自製裝飾，不使用未經授權的遊戲圖片。

## 專案入口

- Repository：https://github.com/Andyyy845/mushoku-character-guide
- 網頁：https://andyyy845.github.io/mushoku-character-guide/witch-trial-wiki/ （需合併分支且啟用 GitHub Pages 才會呈現新版）
- 開發規則：[`AGENTS.md`](./AGENTS.md)
- 本站入口為此層 `index.html`；內部同名資料夾為既有副本，此次未變更。

## 結構與功能

| 檔案 | 用途 |
| --- | --- |
| `index.html` | 語意化首頁、搜尋與分類、非官方聲明、返回頂部 |
| `style.css` | 主題配色、卡片、桌面多欄／手機單欄、焦點及減少動畫 |
| `script.js` | 安全 DOM 渲染、資料檢查、搜尋、分類、重設、失敗重試 |
| `characters.json` | 唯一角色內容來源，保留既有六欄，增加選填 `image` |
| `AGENTS.md` | 後續 AI 必須先讀的內容、開發與驗收規則 |

不需框架、套件、編譯、API 金鑰或外部字型。所有站內資源採相對路徑，支援 GitHub Pages 子路徑。

## 本機預覽

在 Repository 根目錄執行：

```sh
python -m http.server 8000
```

瀏覽 `http://localhost:8000/witch-trial-wiki/`。勿直接雙擊 HTML，否則瀏覽器可能阻擋 JSON 讀取。

## 如何讓 AI 繼續新增內容

請 AI 先閱讀 `AGENTS.md`、`characters.json` 與 `script.js`，再核對官方角色區。複製以下物件到 JSON 陣列，以新角色的已驗證資料取代內容，保留原有六個必要欄位及字串格式，圖片為選填：

```json
{
  "id": "658",
  "name": "桜羽エマ",
  "displayName": "櫻羽艾瑪",
  "description": "樂觀開朗、關心他人，也很在意自己是否被討厭。",
  "magic": "未公開",
  "source": "https://manosaba.com/#character",
  "image": ""
}
```

此例為既有角色，不能直接重複加入。`id` 與 `name` 不得重複；既有 id 不可變更。中文名由卡片統一標註暫譯，魔法未知就填「未公開」。`script.js` 會自動產生卡片、搜尋與篩選結果，無需為每個角色改 HTML、CSS 或 JavaScript。沒有官方囚人編號的角色，須依 AGENTS.md 先調整編號顯示規則。

可重用的提示：

> 請先閱讀 witch-trial-wiki/AGENTS.md，核對官網公開角色區，依既有六欄 JSON 格式加入一位尚未收錄的角色。不要變更既有 id、不要推測未知資訊，僅用已獲網站使用授權的圖片，否則 image 留空。測試搜尋、分類、展開、手機排版及錯誤狀態，只修改 witch-trial-wiki/，以獨立分支提交 PR，列出來源及核對日期。

這套規則將資料、呈現與內容安全分開，後續 AI 能沿用同一個流程擴充內容，避免每次重新設計頁面或自行猜測資料。

## 驗收與部署

1. 測試中文、日文、編號、前後空白及無結果搜尋，再與已公開／未公開分類交叉使用，重設應回到全部角色。
2. 點擊卡片及用 Tab、Enter／空白鍵測試展開收合，確認簡介、魔法及官方來源；手機不能有水平捲動。
3. 確認 JSON 請求失敗或格式錯誤時顯示明確訊息，修復後「重新載入」可恢復。
4. 在桌面與 390px 手機檢查排版、焦點、返回頂部及減少動畫設定。
5. 執行 `git diff --name-only main...HEAD` 確認所有差異都在 `witch-trial-wiki/`，以 PR 審查後才合併。

沿用 Repository 既有 GitHub Pages 設定；若設定為 main / root，合併後使用上述子路徑。此修改不更動根目錄《無職轉生》入口或部署設定。

## 角色圖片與授權

既有六個 JSON 欄位保留，增加向下相容的選填 `image`。舊資料未填此欄、空字串或圖片載入失敗時，都會顯示原本的編號佔位圖。卡片另有「前往官方查看角色圖片」連結。

圖片須先獲得可用於公開網站的授權，再存入 `assets/characters/<id>.webp`（亦可 png、jpg、jpeg、avif），並填入例如 `"image": "./assets/characters/658.webp"`。同時在 [`assets/README.md`](./assets/README.md) 記錄原始來源與授權依據。不使用外站圖片網址；圖片保留比例、提供姓名 alt、延遲載入，缺圖不阻擋文字內容。

2026-11-16 查核官方規範（頁面標示更新於 2026-10-21）：[第 7 節](https://manosaba.com/guidelines)禁止直接將官方插畫、立繪等作為素材轉載；[官方免費圖示](https://manosaba.com/freeicon)明定僅供 SNS 頭像。Google 搜尋結果本身不構成授權。使用者已確認具有公開網站使用授權，並以 ZIP 提供 13 張角色圖片；本次依該聲明加入原始附件，原始上游來源及授權文件未隨附，詳見 assets/README.md。未另行下載或熱連結官網受限制素材。

之後可請 AI：「閱讀 AGENTS.md，依提供的授權角色圖更新 image 和 assets/README.md；檢查角色對應、圖片載入、替代文字與手機排版，不更動既有 id 或其他網站。」

追加圖片功能驗收：舊版六欄資料、空白 image 均正常；使用測試用純色 PNG 驗證本機圖檔載入、姓名 alt、延遲載入、等比例顯示與手機展開。遺失圖檔會回復佔位圖，外站／絕對路徑／路徑穿越／非字串 image 被拒絕。13 張卡片均有官方角色圖片查看連結。13 位簡介皆介於 20～60 字；實際角色圖已依圖上姓名逐張核對並加入，授權依據及附件檔名記錄於 assets/README.md。
